# Experiment protocol

Every registered experiment must state: QUESTION, HYPOTHESIS, CONFIGURATION, BENCHMARK, SEEDS, PRIMARY METRIC, SECONDARY METRICS, RESULT, ROBUSTNESS, INTERPRETATION, LIMITATIONS, and NOVELTY STATUS.

Unit of inference is the independent seed, not the auction round. Report seed-level estimates, uncertainty intervals, attrition/non-convergence, and all preregistered outcomes. Development runs use seeds 0–9; confirmatory seeds and holdouts remain sealed until the protocol is finalized.
