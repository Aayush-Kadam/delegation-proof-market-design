# Holdout protocol

Status: **not frozen; do not evaluate candidate mechanisms on holdouts.**

Before mechanism search, commit a manifest with unseen valuation distributions, algorithm hyperparameters, population sizes, feedback regimes, shock schedules, seed hashes, primary score, guardrails, and rejection thresholds. Development and holdout artifacts must be stored separately. Any post-freeze amendment requires a dated reason and invalidates confirmatory language for affected tests.
