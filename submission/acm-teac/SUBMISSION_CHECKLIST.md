# ACM TEAC submission checklist

- [x] Anonymous manuscript source and PDF prepared
- [x] Separate title page prepared with explicit metadata placeholders
- [x] Cover letter drafted
- [x] Data/code availability statement prepared
- [x] Reproducibility and transparency statements prepared
- [x] Supplement and compact evidence mapped
- [ ] Author name, affiliation, ORCID, correspondence, funding, and conflicts verified
- [ ] Final ACM portal fields and current formatting requirements rechecked at submission time
- [ ] Repository URL and archival DOI inserted after authorized publication
- [ ] Author approves preprint and journal submission
